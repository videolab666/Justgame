# Юст-Оборона: Захисти домівку

Браузерна навчальна гра про захист прав громадян. Реалізація за GDD від 15.10.2026.

## Запуск

Без зовнішніх CDN і без npm-залежностей. У корені проєкту запустіть `python -m http.server 8000` або `npx serve .` та відкрийте `http://localhost:8000`.

## Важливо

Це ігровий прототип. Юридичні відомості перед публікацією на офіційному сайті має затвердити юрист управління. Гра не є юридичною консультацією.
