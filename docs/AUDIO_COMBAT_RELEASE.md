# Оригінальний саундтрек, бойові заставки й діагностика стрільби

## Композиції та ліцензія
У грі використовується **повністю оригінальна** генеративна музика, реалізована у src/music.js засобами Web Audio API. У композиціях немає запозичених мелодій, записів або звукових файлів Plants vs. Zombies; сторонні стокові треки чи бібліотеки не підключені. Принцип музичного оформлення — легкий мультяшний джаз із ксилофоноподібною мелодією, пружним басом, клавішними акордами та тихою перкусією. Мелодії, гармонійні послідовності й ритми створено спеціально для «Юст-Оборони».

| Світ | Композиція | Темп |
| --- | --- | --- |
| Дніпро | Дніпровський двір | 112 BPM |
| Запоріжжя | Заводський джаз | 119 BPM |
| Кропивницький | Прозорі рішення | 105 BPM |
| Цифровий фронт | Цифрова ніч | 124 BPM |

Окремо створено короткі переможну та мінорну завершальні мелодії. Музика синтезується локально у браузері, не завантажує медіафайлів із зовнішніх сайтів, працює офлайн та не передає даних користувачів. Її авторство/дозвіл слід зберігати з вихідним кодом проєкту; жодної ліцензії Pixabay/Pexels не потрібно.

## Керування
- Музика увімкнена для нових гравців. Перший запуск звуку відбувається лише після натискання на кнопку гри або іншої явної взаємодії — так вимагають правила autoplay браузерів.
- Налаштування **Фонова музика** і **Звукові ефекти** незалежні; гучність фонового саундтреку 0–100%.
- На полі є швидка кнопка ♫ для перемикання фонового музичного супроводу.
- Нові музичні ноти не плануються під час паузи, довідкових вікон або коли вкладка прихована.
- У випадку, якщо пристрій не підтримує Web Audio API, гра залишається повністю працездатною без музики.

## Стрільба й перевірка
- Усунуто промах печатки при ближньому контакті: снаряд раніше стартував правіше мінімальної допустимої цілі, тепер запускається з x = колона + 0.4.
- Державний і старший реєстратори, стажер, виконавець, приватний виконавець, експерт, арбітражний керуючий, обмеження й апостиль перевіряються регресійними тестами на реальні постріли.
- Ілюстрація захисника не пересоздається під час кожного бойового кадру, що раніше обривало рух руки.
- Наведіть курсор на клітинку: підказка пояснить, чому захисник не стріляє (туман, замаскована ціль, повітряна/підземна загроза, ворог позаду, блокування здібністю).

## Післяматчеві сцени
Перемога або поразка переводять гравця спершу на окрему кінематографічну заставку. Вона містить анімацію сови Юсі, противника, зірок або сигналу тривоги, відповідну коротку мелодію. За 4 секунди або за натисканням кнопки **«Переглянути статистику»** відкривається звичайний екран статистики. За увімкненого режиму зменшення руху заставка статична й переходить далі після 2,5 секунди. Кнопки Enter/Escape/Пробіл теж дозволяють пропустити заставку.

## Перевірка на пристроях
Автотести Node.js перевіряють механіку снарядів, аудіопартитури та послідовність заставка → статистика. Окремий GitHub Actions workflow **Visual browser QA** перевіряє інтерактивність, відсутність зсувів поля, кнопки фонового звуку й мобільні розміри. Браузерна перевірка не є еквівалентом прослуховування музики на всіх типах пристроїв; для релізу корисно перевірити ще Safari/iOS і недорогі Android-телефони.
