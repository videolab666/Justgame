# Візуальна ідентичність персонажів

Перед редизайном значна кількість персонажів використовувала спільну форму сорочки, очей та капелюха й вирізнялась лише кольорами. Усі 27 персонажів нижче отримали нову SVG-версію з індивідуальним силуетом, головним убором, позою, предметом та палітрою. Малюнки векторні й оригінальні, сторонні зображення не використані.
