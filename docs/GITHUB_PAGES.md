# Гра на GitHub Pages

Це **статичний сайт**, сервер та база даних не потрібні.

Після ввімкнення GitHub Pages у **Settings → Pages → Build and deployment → Source: GitHub Actions** гілка `main` автоматично публікується через `.github/workflows/pages.yml`. Перше налаштування Pages потрібно виконати власнику репозиторію.

За умовчанням адреса: **https://videolab666.github.io/Justgame/**. Це очікувана адреса, а не гарантія активної сторінки до успішного deployment.

**Приватний репозиторій:** на GitHub Free приватні репозиторії не можуть використовувати Pages. Для Pages із приватного репозиторію потрібен Pro/Team/Enterprise. Публікувати код, роблячи репозиторій public, можна лише за вашим рішенням. Навіть Pages приватного репозиторію зазвичай доступні широкій публіці.

## Автоматичний release

1. Workflow запускає `npm test` і завершується помилкою, якщо тест не пройшов.
2. `node scripts/build-site.mjs` копіює **лише** файли гри до `dist/`, не публікуючи вихідні тестові матеріали, GDD, issues, docs тощо.
3. `actions/deploy-pages` публікує сайт.

Перевірка статусу: **Actions → Test and publish game to GitHub Pages**. Якщо Actions відхиляє `configure-pages` або `deploy-pages`, перевірте, чи активовано Pages і план підтримує приватний репозиторій.

## Локальний запуск

```sh
python -m http.server 8000
# http://localhost:8000/
```

Скрипт використовує відносні шляхи до CSS, JavaScript та локальних активів, тому працює і з кореня домену, і у підпапці /Justgame/.

## Ліцензування арт-ресурсів

Базова графіка гри — оригінальні локальні SVG ілюстрації; зовнішні ресурси не викликаються. Якщо пізніше додаються моделі Sketchfab, кожен файл повинен мати перевірену сумісну ліцензію, URL джерела й автора у реєстрі assets. Моделі CC-BY потребують атрибуції; assets з обмеженням editorial-only непридатні для вільного промоційного використання.
